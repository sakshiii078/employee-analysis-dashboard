# Employee Analysis Dashboard

## Overview
A beginner-friendly Excel dashboard created to analyze employee
data and understand workforce trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel KPIs
- Slicers

## Dataset
The dataset contains employee information such as:
- Employee ID
- Name
- Department
- Experience
- etc.

## Key Analysis
- Employee distribution by department
- Experience analysis
- Workforce overview
- Department-wise trends
